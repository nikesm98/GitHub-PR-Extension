# Changelog

All notable changes to the "GitHub PR Viewer" extension will be documented in this file.

## [0.1.0] - 2026-05-21

### Added

- VS Code built-in GitHub authentication (zero-config OAuth)
- Personal Access Token authentication (fallback)
- Organization listing in sidebar tree view
- Pull request listing per organization
- Rich PR details webview panel with statistics, labels, reviewers, and branch info
- PR state filtering (Open / Closed / All)
- Draft PR detection and display
- In-memory caching with configurable TTL
- Auto-refresh with configurable interval
- Status bar integration (auth status, PR count, quick refresh)
- Company email domain validation (configurable, optional)
- Structured logging via VS Code Output Channel
- Content Security Policy on all webviews
